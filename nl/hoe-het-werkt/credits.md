# Het creditsysteem

dGENIX werkt met credits. Elke taak die GENI, je AI-assistent, uitvoert verbruikt credits. Zo betaal je alleen voor wat je echt gebruikt.

---

## Wat zijn credits?

Credits zijn de rekeneenheid van dGENIX. Ze worden verbruikt wanneer GENI:

- Een AI-taalmodel gebruikt om te denken, schrijven of samenvatten
- Data ophaalt en verwerkt (leads, e-mails, onderzoeksresultaten)
- Een skill uitvoert (bijvoorbeeld Gmail lezen, een afbeelding genereren, een SEO-audit draaien)

Een gemiddelde taak kost ongeveer 100 credits. Een korte chat kost minder, een zware actie (een volledige site-audit, een AI-video met clips) meer. Je betaalt naar verhouding van het werk.

---

## Hoeveel credits heb ik per maand?

| Plan | Credits/maand | ~Taken |
|---|---|---|
| Free | 1.000 (harde limiet) |, |
| Starter | 75.000 | ~750 |
| Growth | 175.000 | ~1.750 |
| Pro | 350.000 | ~3.500 |
| Business | 1.000.000 | ~10.000 |
| Custom | Op maat | Onbeperkt |

Je credits worden elke maand automatisch aangevuld op je facturatiedatum. **Ongebruikte credits vervallen** aan het einde van de periode, ze worden niet meegenomen.

## Wat kost een taak? (richtprijzen)

| Taak | ~Credits |
|---|---|
| AI-chatgesprek (kort) | ~20 cr |
| E-mail lezen / inbox samenvatten | ~5-15 cr |
| Afspraak plannen | ~10 cr |
| Bestand zoeken in Drive | ~5 cr |
| Social media post | ~2 cr |
| Web search | 75 cr per zoekopdracht |
| AI-afbeelding genereren (Nano Banana) | 500-1.700 cr |
| Audio transcriberen | 12-20 cr per minuut |
| SEO Engine audit | 1.500-22.000 cr (per diepte) |
| GEO Engine audit | 8.000-95.000 cr (per diepte) |
| AI Content Engine (video -> clips) | 500 cr + 600 cr per clip |

> De exacte kosten van een skill staan altijd op de knop in het dashboard voordat je een actie start. Mislukt een betaalde actie? Dan worden de credits automatisch teruggestort.

---

## Wat als mijn credits op zijn?

Als je saldo te laag wordt, stopt GENI met het uitvoeren van nieuwe betaalde taken en krijg je een melding. Je kunt dan:

- **Bijkopen** (vanaf Starter), een eenmalig [credit pack](../plannen-en-prijzen/credits-bijkopen.md) (S t/m XXL)
- **Wachten op verlenging**, credits worden aangevuld op je facturatiedatum
- **Upgraden**, naar een plan met meer credits per maand

Zodra je saldo weer voldoende is, gaat GENI automatisch verder.

---

## Waar zie ik mijn creditsaldo?

- **Dashboard -> Home**, huidig saldo, percentage gebruikt en je vernieuwingsdatum, bovenaan in de stat-rij.
- **Dashboard -> Account -> Gebruik**, een gedetailleerd overzicht van alle transacties: welke acties hoeveel credits hebben gebruikt, per dag en per functie.

## Engine-credits (Growth Engines-abonnement)

Gebruik je de SEO-, GEO-, Authority- of backlink-tools intensief? Dan kun je een optioneel **Growth Engines-abonnement** nemen met een aparte **engine-credit-wallet**. Die wallet wordt elke maand bijgevuld en wordt **eerst** aangesproken bij engine-acties, daarna pas je gewone plan-credits. Zo verbruik je je gewone credits niet aan zware audits. Engine-credits werken alleen voor de engines. Zie [Plannen & Prijzen](../plannen-en-prijzen/README.md) voor de tiers. In de Groei Tools-hub zie je hoeveel engine-credits je nog over hebt deze maand.
