# Upcoming features

dGENIX grows continuously. Here is what is coming soon, and what was recently shipped.

---

## Coming soon

### Microsoft 365

Work with Outlook, Teams and Microsoft Calendar via GENI: plan emails, book meetings and create tasks in Teams, all from one place.

- **Plan:** included from Growth+
- **Status:** waiting on Azure OAuth verification

### Canva

Design and edit Canva designs straight through GENI: create a design, apply a template or export a design, without opening the Canva editor.

- **Plan:** included from Growth+
- **Status:** waiting on Canva developer credentials

### MCP connectors

Connect hundreds of external tools via the Model Context Protocol (MCP), on your own account. Read more in [MCP connectors](../connectors/mcp-connectors.md).

- **Status:** rolling out
