# Document Reader

The Document Reader skill analyses and summarises PDF files and text documents you upload.

---

## What can your assistant do?

- Summarise PDFs and text documents
- Extract key points and conclusions
- Answer questions about a document's content
- Compare multiple documents
- Highlight or translate specific sections

---

## Requirements

- **Plan:** Starter, Growth or Pro (included in all plans)
- **Integration:** none, the skill works without an extra connection

---

## How do you activate Document Reader?

1. Go to **Dashboard -> Skills**
2. Click **"Activate"** on Document Reader
3. The skill is active right away, upload a file via **Dashboard -> Files** or share it in the chat

---

## Example commands

```
Summarise this contract in 5 bullets
```
```
What are the key clauses in this document?
```
```
Compare document A and document B, what are the differences?
```
```
Translate the summary of this report into English
```

| Type | Format |
|---|---|
| PDF | .pdf |
| Text | .txt, .md |
| Word | .docx (via text extraction) |
