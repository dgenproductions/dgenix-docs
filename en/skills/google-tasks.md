# Google Tasks

Create, view and complete tasks in Google Tasks via your AI assistant. Synced with your Google account.

**Requirements:** Starter+ plan (all paid plans), connect a Google account via Connectors

---

## Available actions

| Action | Credit cost | Description |
|---|---|---|
| `get_tasks` | 15 cr | Get open tasks from a task list |
| `create_task` | 15 cr | Create a new task with a title and optional due date |
| `complete_task` | 15 cr | Mark a task as complete |
| `plan_tasks` | 25 cr | Prioritise a task list by urgency and deadline |

---

## Connecting

1. Go to **Connectors**
2. Click **Connect** on Google Tasks
3. Log in with your Google account
4. Grant permission for `tasks` (read and write)

---

## Example conversations

**Get tasks:**
> "What's on my Google task list for today?"

**Create a task:**
> "Add 'send quote to Jan' to my task list for Friday"

**Complete a task:**
> "Check off 'send invoice' in my task list"

**Plan tasks:**
> "Prioritise my open tasks by urgency"

---

## Tips

- Use Google Tasks together with the Daily Planner skill for a complete overview
- Set due dates when creating tasks so prioritisation works correctly
- Deadline tasks sync with Google Calendar
- Use a specific list name if you have multiple lists

---

## Limitations

- Subtasks are not supported via the Google Tasks API
- Creating recurring tasks is not available
- Creating or deleting task lists is not possible via this skill
