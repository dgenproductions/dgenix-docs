# AI Image Editing

With the Image Editing skill GENI scales, crops and optimises your images to the format you need, without opening an image editor.

Available from **Starter**. No connection needed.

## What can GENI do with image editing?

- **Rescale an image** to a given size
- **Crop** to the ratio a platform asks for
- **Compress** so the file gets smaller without visible quality loss

Useful when you have one image and need it in four places: a LinkedIn post, a
website header, an email and an Instagram square all want something different.

```
Turn this photo into a LinkedIn header and an Instagram square
```

## Limits

- **It does not edit the content.** Removing objects, replacing backgrounds or drawing something in is not possible; for that use [AI image generation](ai-beeldgeneratie.md) in editing mode.
- **No adding text or layout.** For design with text, Canva is a better fit.
- **Upscaling has limits.** A small, grainy photo does not get sharper by enlarging it.
- **One image per request.** A series you do one by one.
- **The original stays untouched.** You get a new version back.

## Troubleshooting

**The crop lands wrong.** Say what matters ("keep the face in frame") and GENI crops around it.

**The file is still too large.** Ask for stronger compression or a smaller size; below a certain size quality degrades noticeably.

**Quality disappoints after enlarging.** There is no more detail in the original than there is. Work from a larger source image.

**Your image is refused.** Check the format; the common image formats you can also send in chat are supported.

## Frequently asked questions

**What is the difference with AI image generation?**
Image generation creates a new image from a description. This skill edits an
existing one. See [AI image generation](ai-beeldgeneratie.md).

**Where do the edited files end up?**
In your Workspace, Files tab. See [Files](../functies/bestanden.md).

**Can it process a whole folder?**
No, one image at a time. For large volumes a dedicated image editor is more
efficient.

**Does it cost credits if I do not like the result?**
The edit was performed, so it counts. Describe what you want as precisely as
possible up front.
