# Connect Telegram

Telegram is an extra interface alongside the dGENIX dashboard, both channels are kept in sync.

---

## Connecting

1. Install [Telegram](https://telegram.org) on your phone or computer
2. Go to **Dashboard -> Skills** and activate the Telegram add-on
3. Follow the linking steps (link code)
4. Send `/start` (with your link code) to [@dGENIXbot](https://t.me/dGENIXbot) to activate your assistant

---

## Commands

| Command | Function |
|----------|---------|
| `/start` | Activate the assistant and get a welcome message |
| `/credits` | Get your current credit balance |
| `/help` | Quick list of available commands |

---

## Voice messages

Send a voice message via Telegram, the assistant transcribes it automatically and processes it as text. No extra steps needed.

---

## Web to Telegram sync

Messages you send via the **AI Assistant page** in the web app are forwarded to Telegram (and vice versa). Your conversation history is always synced between web and Telegram.

---

## Own Telegram Bot (Pro+)

With the **Own Bot** (included from Pro) you use your own bot token. Benefits:
- Your own name and profile picture for the assistant in Telegram
- A fully personalised chat experience

Activating:
1. Create a bot via [@BotFather](https://t.me/BotFather) in Telegram
2. Copy the bot token
3. Activate the Own Bot via the Skills Marketplace
4. Enter the token via Dashboard -> Skills -> Own Telegram Bot

---

## Troubleshooting

**Assistant not responding:**
- Check that Telegram is connected via Dashboard -> Skills
- Use the "Restart assistant" button
- Check your credit balance

**Lost connection:**
- Go to Dashboard -> Skills and reconnect

**Other issues:**
- Open a support ticket via Help & Support in the dashboard
