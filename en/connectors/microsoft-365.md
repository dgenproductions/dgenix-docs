# Connect Microsoft 365

> **Coming soon**, the Microsoft 365 connection is in preparation and arrives once the Azure OAuth verification is complete.

---

## What's supported

After activation the connection gives access to:

- **Outlook**, read, write and send emails
- **Microsoft Calendar**, view your calendar and schedule appointments
- **OneDrive**, save and fetch files

---

## Permissions (after activation)

| Scope | For |
|---|---|
| `Mail.ReadWrite` + `Mail.Send` | Outlook email |
| `Calendars.ReadWrite` | Calendar |
| `Files.ReadWrite.All` | OneDrive files |
| `User.Read` | Profile data |
