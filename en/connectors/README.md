# Connectors

Connectors are external links you add to your AI assistant. Via **Dashboard -> Connectors** you connect your tools once, after that GENI uses them automatically on relevant tasks.

---

## How it works

1. Go to **Dashboard -> Connectors**
2. Pick the connector you want to link
3. Complete the authorisation step (OAuth or enter an API key)
4. The connector is immediately available for all related skills

## OAuth vs. API key

**OAuth (click + authorise):** Gmail, Google Calendar, Google Drive, Google Sheets, Docs, Tasks, Analytics, Search Console, Business Profile, Slack, Notion, LinkedIn, Microsoft 365, Canva, Airtable, Typeform, Calendly

**API key (enter a token):** WhatsApp Business, Instagram Business, Stripe, HubSpot
